# 📋 ระบบสัญญาจ้างทีมงานถ่ายทำ — Superman

ระบบสร้างสัญญาจ้างทีมงานถ่ายทำสำหรับ **บริษัท ซุปเปอร์แมน จำกัด** แบบ Web App ไฟล์เดียว ไม่ต้องติดตั้ง ไม่ต้องมีเซิร์ฟเวอร์

🌐 **Live Demo:** https://ratapongp.github.io/superman-contract/

---

## ✨ ฟีเจอร์หลัก

- **กรอกฟอร์มแล้วได้สัญญาทันที** — กรอกชื่อ ตำแหน่ง วันที่ ค่าจ้าง แล้วเอกสารจะสร้างให้อัตโนมัติ
- **Preview แบบ Real-time** — เห็นหน้าตาเอกสารจริงก่อน export
- **Export PDF** — กดปุ่มเดียว เปิด print dialog พร้อม Save as PDF ได้เลย
- **รองรับภาษาไทยเต็มรูปแบบ** — ฟอนต์ Kanit / DB Heavent
- **อัปโหลดโลโก้ได้** — คลิกที่โลโก้มุมซ้ายบนเพื่อเปลี่ยนรูป
- **บันทึก-โหลดสัญญา** — บันทึกข้อมูลทีมงานไว้ใช้ซ้ำ แก้ไขได้ภายหลัง
- **ไม่มี backend** — ทำงานบน browser ล้วน ข้อมูลไม่ออกไปไหน

## 📄 รายละเอียดเอกสารที่สร้างได้

| ช่อง | รายละเอียด |
|------|------------|
| ชื่อ-นามสกุล | ชื่อผู้รับจ้าง |

| โปรเจกต์ | ชื่องาน/โปรเจกต์ที่จ้าง |

| ค่าจ้าง | จำนวนเงิน + เงื่อนไขการจ่าย |
| ข้อมูลธนาคาร | ชื่อธนาคาร, เลขบัญชี, ชื่อบัญชี |
| ลายเซ็น | พื้นที่เซ็นชื่อทั้ง 2 ฝ่าย |

## 🚀 วิธีใช้งาน

### ใช้ผ่านเว็บ (แนะนำ)
เปิด https://ratapongp.github.io/superman-contract/ ใน browser ได้เลย

### ใช้แบบ Offline
1. ดาวน์โหลด `index.html`
2. เปิดไฟล์ใน browser โดยตรง
3. ใช้งานได้ทันทีโดยไม่ต้องเชื่อมอินเทอร์เน็ต (ยกเว้นโหลด font ครั้งแรก)

---

## 🖨️ วิธี Export PDF

1. กรอกข้อมูลให้ครบ (ชื่อ, ตำแหน่ง, โปรเจกต์)
2. กดปุ่ม **📄 บันทึก PDF**
3. ใน dialog ที่ขึ้นมา เลือก **Destination → Save as PDF**
4. กด **Save**

> **Tip:** ตั้ง Margin เป็น "None" ถ้าต้องการให้ได้ขนาดพอดี A4

## 🛠️ Tech Stack

| เทคโนโลยี | การใช้งาน |
